# Cooray

휴대폰에서 쓰는 두레이 보조 안드로이드 앱입니다. 메일·오늘·업무·위키·드라이브·메신저·캘린더·게시판·자원예약을
휴대폰 화면에 맞게 모아 보고, 홈 화면 위젯으로 달력과 일정을 바로 봅니다.
**무료로 쓸 수 있습니다.**

> **공개 배포가 아닙니다.** NHN 의 운영 정책상 두레이의 비공식 클라이언트는 공개 배포가
> 승인되지 않습니다. 그래서 이 앱은 공개 서비스가 아니며, **지정된 대상에게만 배포합니다.**
> 여기 있는 파일은 그 대상을 위한 것입니다.

소개와 설치 방법: **https://dev.chilgong88.com/cooray**

## 이 저장소에 대해

**이 저장소는 배포 전용입니다.** 설치 파일을 내려받는 곳이며, **소스 코드는 공개하지 않습니다.**
받으실 파일은 [Releases](../../releases) 에 있습니다.

## 받는 법

[Releases](../../releases) 에 기기별로 파일이 둘 있습니다. **하나만** 받으시면 됩니다.

| 파일 | 어느 휴대폰 |
|---|---|
| `Cooray-<버전>-arm64-v8a.apk` | 대부분의 휴대폰 (64비트) |
| `Cooray-<버전>-armeabi-v7a.apk` | 오래된 32비트 휴대폰 |

위의 것을 먼저 받아 보시고, 설치되지 않으면 아래 것을 받으세요.
스토어에서 받는 앱이 아니라 설치 파일을 직접 받아 설치하는 방식이라, 처음에는 휴대폰이 경고를 보여 줍니다.
넘어가는 순서는 [설치 방법](https://dev.chilgong88.com/cooray)에 단계별로 적어 두었습니다.

각 릴리스에 파일의 SHA-256 과 서명 인증서 지문을 함께 적어 둡니다. 받은 파일이 맞는지 확인하고 싶으면
비교해 보세요.

이미 쓰고 계신 분은 지우지 않고 그대로 설치하면 업데이트됩니다. 다만 **0.1.3 보다 앞선 판을 쓰고
계시면** 서명 키가 달라 설치가 막히므로, 지우고 새로 설치해야 합니다.

## 알아 두실 점

- **NHN Dooray 공식 앱이 아니며 NHN 과 관계가 없습니다.** 두레이를 쓰면서 따로 만든 보조 앱입니다.
- **알림은 공식 앱을 함께 쓰시기를 권합니다.** 이 앱의 알림은 새 소식을 확인해 알려 주는 방식이라
  공식 앱보다 늦을 수 있습니다.
- 스토어를 거치지 않은 앱이라 설치할 때 **Play 프로텍트 경고**가 나올 수 있습니다.
  **자세히 → 무시하고 설치** 를 누르면 계속 진행됩니다.
- 처음 실행하면 두레이 주소와 아이디, 비밀번호를 넣습니다.
